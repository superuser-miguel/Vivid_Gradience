Vivid Gradience

Change the look of Adwaita, with ease.

A maintained fork of Gradience, brought back to the current GNOME runtime. Recolour every part of the Adwaita palette, start from one of 53 ready-made colour schemes, and apply it to Libadwaita, GTK 4 and GTK 3 apps — without hand-editing a single config file.

Download (.flatpak) View on GitHub

Why this fork exists

The original was archived in June 2024. This picks it back up.

Current runtime

Builds and runs on GNOME 50, and a weekly job bumps the manifest and build-tests it before the change lands.

A modern interface

Rebuilt on current libadwaita — ToolbarView, adaptive Breakpoint layout, boxed lists, and the newer row widgets.

Themes you'd actually use

53 community colour schemes built in — Catppuccin, Gruvbox, Nord, Dracula, Rosé Pine, Everforest, Solarized, Tokyo Night and more.

Features

Everything from upstream, plus the parts it never got round to.

A visual preset gallery

Every scheme is a card tinted with its own background colour, showing its character hues. Click one to load it.

Searchable colour editing

All 46 named Adwaita colours, in collapsible categories with a search box — picker or hex, whichever you prefer.

A palette from your wallpaper

The Monet engine extracts a Material Design 3 palette from any image and turns it into a full scheme.

GNOME Shell theming

Generate a matching Shell theme from the current preset, without leaving the app.

Custom CSS

An escape hatch for anything the colour variables can't express, per toolkit.

Adaptive down to mobile

The window reflows to narrow widths, moving the view switcher to a bottom bar.

A look around

Four tabs: pick a scheme, tune it, apply it, then go further.

Install

A single-file Flatpak bundle from GitHub Releases.

flatpak install --user ./VividGradience.flatpak
flatpak run io.github.superuser_miguel.VividGradience

A bundle carries no auto-update — a newer release means downloading and reinstalling it. Vivid Gradience is not on Flathub and is distributed independently.

Theming setup

Native apps need nothing. Sandboxed ones need one permission.

Libadwaita & GTK 4 Flatpaks

Grant access to the GTK 4 config: sudo flatpak override --filesystem=xdg-config/gtk-4.0, or the same entry in Flatseal.

GTK 3 apps

Install adw-gtk3, then grant xdg-config/gtk-3.0 the same way.

Roadmap

Honest about what's next. (The preset gallery, the modernised UI and runtime tracking already shipped.)

  • Theme installs from GitHub and .zip — fetch and install themes from inside the app, managing the stylesheet it shares with them rather than overwriting it.
  • Time-of-day theme cycle — assign presets to day, afternoon and night and switch automatically, on a schedule or by sunrise and sunset.
  • Light/dark preset pairs — follow the system colour scheme with a matched pair.
  • Colour wheel — a proper wheel for picking, alongside the hex fields.
  • Your own presets in the gallery — user presets shown as cards, like the built-in schemes.
  • Generate a preset from one colour, plus textures and a fuller theme preview.

A unified Adwaita look matters for app developers — see stopthemingmy.app. This is a tool for tinkerers, not something distributions should ship by default.
