# Screenshots

Place PNG screenshots here. They're referenced from the top-level `README.md`.

Expected filenames (used by the README):

- `presets.png` — the Presets gallery (the hero shot)
- `colors.png` — the Colors editor (searchable, collapsible categories)
- `theming.png` — the Theming tab (Monet / Shell engines)
- `advanced.png` — the Advanced / Custom CSS tab (optional)

Tips:

- Use a consistent window size and a clean desktop background.
- HiDPI (2×) captures look crisp on GitHub; keep widths reasonable (~1400px).
- The AppStream `<screenshots>` block needs **hosted URLs**, not repo paths — so
  those come from the GitHub Pages site once it exists. That's a separate step
  from these README images.
